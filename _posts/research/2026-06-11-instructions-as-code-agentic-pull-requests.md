## Ringkasan

AI agent seperti GitHub Copilot kini berkolaborasi sebagai rekan satu tim dalam berbagai tugas rekayasa perangkat lunak, termasuk pembuatan kode melalui pull request (Agentic-PR). Studi ini meneliti bagaimana file instruksi — seperti README, CONTRIBUTING.md, dan file markdown lainnya — memengaruhi efektivitas agen dalam menghasilkan PR yang akurat. Penulis menemukan bahwa kejelasan, struktur, dan kelengkapan instruksi secara signifikan memengaruhi kualitas output agen, membuka jalan menuju paradigma 'Instructions-as-Code'.

## Poin-Poin Penting

* File instruksi (README, CONTRIBUTING.md) sangat memengaruhi kualitas Agentic-PR.
* Instruksi yang terstruktur dan eksplisit menghasilkan output agen yang lebih akurat.
* Konsep 'Instructions-as-Code': instruksi diperlakukan sebagai artefak pertama dalam pengembangan.
* Implikasi: tim perlu mendesain repositori dengan instruksi yang ramah AI agent.
* Studi empiris menunjukkan peningkatan signifikan dalam akurasi PR dengan instruksi yang baik.

## Mengapa Ini Penting

Seiring agen AI menjadi kontributor kode yang setara dengan manusia, kualitas instruksi menjadi faktor penentu. Tim pengembang perlu mengadopsi praktik baru dalam penulisan dokumentasi yang dioptimalkan untuk konsumsi AI agent.

## Dampak Masa Depan

Paradigma 'Instructions-as-Code' akan menjadi praktik standar dalam pengembangan perangkat lunak berbasis AI. Repositori yang dirancang dengan instruksi ramah-agen akan memiliki keunggulan kompetitif dalam produktivitas dan kualitas kode.
