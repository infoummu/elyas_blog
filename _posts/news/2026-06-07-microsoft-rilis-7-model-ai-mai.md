## Ringkasan

Microsoft menggebrak ajang Build 2026 dengan meluncurkan tujuh model kecerdasan buatan sekaligus di bawah keluarga Microsoft AI (MAI). Langkah ini menandai ambisi Microsoft untuk mengandalkan model AI buatan sendiri, tidak hanya mengandalkan teknologi OpenAI seperti selama ini. Tujuh model tersebut mencakup kemampuan penalaran, pemrograman, pembuatan gambar, transkripsi suara, hingga sintesis suara.

Model unggulan MAI-Thinking-1 adalah model reasoning pertama Microsoft dengan 35 miliar parameter dan jendela konteks hingga 128.000 token. Microsoft juga merilis MAI-Code-1-Flash untuk GitHub Copilot dan Visual Studio Code, MAI-Image-2.5 untuk pembuatan gambar, serta MAI-Voice-2 dan MAI-Transcribe-1.5 untuk kebutuhan suara. Meski demikian, Microsoft tetap mempertahankan hubungan strategis dengan OpenAI dan sudah menyepakati kerja sama hingga 2032.

## Poin-Poin Penting/Fakta

* Tujuh model AI keluarga MAI: MAI-Thinking-1, MAI-Code-1-Flash, MAI-Image-2.5, MAI-Voice-2, MAI-Transcribe-1.5, dan model lainnya
* MAI-Thinking-1: 35 miliar parameter, konteks 128.000 token, untuk penalaran kompleks
* MAI-Code-1-Flash diintegrasikan ke GitHub Copilot dan VS Code untuk coding
* MAI-Image-2.5 mampu membuat dan mengedit gambar dari perintah teks
* MAI-Voice-2 mendukung berbagai bahasa dengan ekspresi suara natural
* Sebagian besar model akan diintegrasikan ke Copilot, PowerPoint, dan Azure AI Foundry
* Microsoft tetap menjalin kerja sama dengan OpenAI hingga 2032
